# BugSafari Remediation Plan

> Derived from `REVIEWS.md`. Ordered for a subsequent `/goal` execution turn — each step is independently verifiable and low-blast-radius unless noted. Fix in order; do not skip ahead to dead-code removal before security fixes are verified.

## Phase 1 — Security fixes (do first, small diffs, high impact) ✅ DONE
1. ✅ `authController.ts` password reset: reset token is now bcrypt-hashed before storing and compared via `bcrypt.compare`, not raw `!==`.
2. ✅ `registerRoutes.ts` `POST /api/safari/stop`: now runs through `optionalAuth` and rejects (403) any requester whose userId doesn't match the active session's owner.
3. ✅ `authConfig.ts`: throws on boot if `NODE_ENV === 'production'` and `JWT_SECRET` equals the hardcoded dev fallback value.
4. ✅ `index.ts` CORS: kept `cors()` / `origin: '*'` but documented inline why it's intentional — auth is JWT-Bearer-only (no cookie session), so a wildcard origin isn't CSRF-exploitable; a comment now warns against adding `credentials: true` without also adding an allow-list.
5. ✅ `historyService.ts`: token-prefix `console.log` removed.

## Phase 2 — Concurrency / correctness fixes ✅ DONE
6. ✅ `StartExplorationUseCase` + `registerRoutes.ts`: TOCTOU race closed via `tryActivate()`/`releaseActivation()`, claimed synchronously in the route handler before any `await`. Regression test added: `StartExplorationUseCase.concurrency.test.ts`.
7. ✅ `PlaywrightBrowserEngine.ts`: replaced the message-substring `TypeError` catch with an explicit `cancelledDuringRun` tag set by `stop()`, so only genuine cancellations are swallowed.
8. ✅ `MongoFindingRepository.collectBugFindings`: now accepts an optional `userId` and filters by it (with `isValidObjectId` guard), matching `listSessionHistory`'s ownership filter.
9. ✅ `useRegressionVerifier.ts`: reads `token` from `useAuth()` and tears down/reopens the socket when the token changes, instead of caching it at socket creation.
