Client Render Freeze
High
CWE-834
Message
Client render freeze: the main thread was blocked, so the page could not respond to input or repaint.
Reproduction Playbook

1
click
Click 5 controls at the same time: the "Academics ▾" button, the "Student Services ▾" button, the "← Back to Events" link, the "LANI Scholarship" link and the "Registrar's Office" link
Observed result
5 of 5 clicks registered in 218ms
Suggested Fix

Suggested fix: free the main thread
1. Move long synchronous work (large loops, parsing, layout) off the main thread with a Web Worker, or split it into async chunks so the view can paint
2. If the view keeps re-rendering, find a state update inside render or an effect with no dependency guard (setState triggers render, which triggers setState again)
3. Look for a subscription or observer that re-adds nodes on every change (toasts, live feeds, infinite scroll)
4. Memoize derived values so a new object each render cannot keep retriggering the effect
